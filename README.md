Uma aplicação web utilizando linguagem de marcação para instruir **pais de primeira viagem** a como agir e boas práticas com o seu filho recém nascido

## 📄 Sobre o projeto

A atividade proposta pelo professor Vedilson, combinou perfeitamente com o contexto que estamos vivendo dentro da sala de 
aula. Recentemente, recebemos a notícia de que ele irá se tornar pai e observa-se mundo afora que exitem diversos guias para a maternidade
mas, quando se trata do **pai**, acha-se menos guias de instrução. Ouvindo isso pensei comigo mesmo "fá-lo-ei um site em tua homenagem".

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias puras do desenvolvimento web para garantir o máximo de performance e customização, sem dependência de frameworks pesados:

- **HTML5**: Estruturação semântica em formato de slides.
- **CSS3 (Vanilla)**:
  - Design Responsivo e Variáveis CSS (Design Tokens).

## 📂 Estrutura do Projeto

Para garantir manutenibilidade e escalabilidade, o código foi separado seguindo boas práticas de desenvolvimento: 

```text
📦 atividade-paternidade
 ┣ 📂 assets
 ┃ ┗ 📜 papai-do-ano.jpg # Imagem utilizada em uma das p[aginas
 ┣ 📂 css
 ┃ ┗ 📜 style.css        # Variáveis Globais e Layout
 ┣ 📂 pages
 ┃ ┗ 📜 cuidados-diarios.html # Guia de cuidados diários 
 ┃ ┗ 📜 recem-nascido.html    # Guia para recém-nascidos
 ┃ ┗ 📜 rede-de-apoio.html    # Rede de apoio para os pais
 ┣ 📜 index.html        # Estrutura do projeto e marcação
 ┗ 📜 README.md         # Documentação do projeto
```
